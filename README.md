# Sorting Algorithms Analysis
A Python project comparing the behaviour and runtime performance of several sorting algorithms.

## Overview
The project implements Bubble Sort, Merge Sort and Quick Sort from scratch and compares their execution time on generated numerical datasets.
The goal was to explore how different sorting algorithms behave as input size increases.

## Algorithms Implemented
- Bubble Sort
- Merge Sort
- Quick Sort

## Analysis
The program:
- Generates numerical datasets using NumPy and Python
- Sorts the data using three different algorithms
- Measures execution time using `perf_counter`
- Repeats measurements to calculate average runtime
- Evaluates performance across increasing input sizes
- Visualises the results using Matplotlib
